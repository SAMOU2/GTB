# 📚 GTB - Système de Gestion de Bibliothèque (Library Management System)

**GTB** est une application Java robuste conçue pour automatiser et simplifier la gestion des flux documentaires au sein d'une bibliothèque. Elle permet de gérer efficacement le catalogue d'ouvrages, les membres et le cycle complet des emprunts.

## 🚀 Fonctionnalités Clés

- **Gestion du Catalogue** : Ajout, modification, suppression et recherche avancée de livres.
- **Suivi des Membres** : Base de données des lecteurs avec historique d'activité.
- **Système d'Emprunts** : Automatisation du processus de prêt et de retour avec gestion des dates limites.
- **Interface Intuitive** : UX optimisée pour une prise en main rapide par le personnel administratif.
- **Persistance des Données** : Intégration sécurisée avec une base de données relationnelle.

## 🛠️ Stack Technique

- **Langage :** Java (JDK 8 ou supérieur)
- **Base de données :** Oracle SQL / JDBC
- **Interface :** Java Swing / AWT (ou JavaFX si applicable)
- **Architecture :** MVC (Modèle-Vue-Contrôleur) pour une séparation claire de la logique et de l'interface.
